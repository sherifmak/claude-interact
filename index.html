claude-loop · a pattern + a 1-file library

Interfaces that talk back .

Claude Code is so good at code that it can hand you a real, purpose-built interface for any task. The missing half is the way back. This closes it.

Try the demos View on GitHub

For two years every conversation with an AI has been squeezed through a chat box. You type a paragraph hoping it lands; it types a paragraph back. But a paragraph is a terrible way to pick a colour, reorder a plan, or approve three of five steps. Clicking beats typing for structured input — that's the entire reason we left command lines behind in the 80s.

Now the agent can simply build the right control for the job — a slider, a set of chips, a drag-to-reorder list — render it as plain HTML, and open it in your browser. Anthropic noticed the same thing: HTML is an unreasonably good output format for Claude Code. But generating the interface is only half a loop. When you tweak that slider, where does the answer go?

claude-loop is the answer: a single file you drop into any HTML Claude generates. It watches your inputs and, with one click, prints a tidy receipt of everything you chose — copied to your clipboard, ready to paste straight back into the chat. No server, no install, no account. The interface talks; now it talks back.

04

Use it with Claude Code

Paste this into your Claude Code session once. From then on, when you ask for a plan, a design, or a set of choices, Claude will hand you a loop-enabled interface — and you can send your answers straight back.

# Give this to Claude Code (also in PROMPT.md)
When I ask you to show me a plan, a design, or a set of options,
build it as a single HTML file and open it in my browser.

Make the choices interactive — sliders, chips, drag-to-reorder
lists, editable text, approve/revise buttons — never a wall of text.

Include claude-loop so I can send my answers back to you:
  <link rel="stylesheet" href="loop.css">
  <script src="loop.js" defer></script>
Mark each control with data-loop="Friendly label", lists with
data-loop-order, and decisions with data-loop-decision.

When I paste back a "claude · loop receipt", treat it as my chosen
input and apply it to what you generated.
